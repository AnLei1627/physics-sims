第10堂　轉動力矩

AP Physics C 力學。五個課堂示範，公式留在畫面上，數字可以用滑桿改。

  • 細棒與硬幣：一端為軸、從水平放開。桿端一開始向下的加速度是 3g/2，硬幣分離。標出速率始終等於自由落體的 x = 2L/3。
  • 開門的力矩：俯視。拖施力點和方向，看 r、F、力臂和 τ = rF sinθ。作用線過鉸鏈時 τ = 0。
  • 有質量的 Atwood 滑輪：均勻圓盤 I = ½MR²。比較掛重量 mg 和用固定力 mg 拉繩。
  • 斜面滾動比賽：實心球、實心圓柱、厚壁空心圓柱、薄圓環。可改成無摩擦、只滑不轉。
  • 滑冰者收臂：L = Iω 守恆。動能增加的部分是肌肉做的功。
